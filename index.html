6 Integrasi Google Spreadsheet & Cloud Apps Script

Cloud Sync & Backup

Masukkan Web App URL hasil deployment file Code.gs di Google Spreadsheet lembaga.

Panduan Langkah Integrasi ke Google Spreadsheet (Klik untuk membuka)
1
Buka Google Spreadsheet Baru: Masuk ke Google Drive menggunakan akun turatscorner.alaqsha@gmail.com atau akun lembaga, buat spreadsheet baru dengan nama misalnya Database Absensi Kutubutturats Al-Aqsha.
2
Buka Apps Script: Pada spreadsheet tersebut, klik menu Ekstensi (Extensions) > Apps Script.
3
Salin Kode Backend: Hapus semua kode default di editor, buka file Code.gs di aplikasi ini, salin seluruh kodenya dan tempelkan ke editor Apps Script.
4
Deploy Web App: Klik tombol Deploy (Terapkan) di kanan atas > pilih New Deployment (Penerapan Baru) > pilih jenis Web App. Atur:
  • Execute as: Me (Saya)
  • Who has access: Anyone (Siapa saja) ← Wajib agar ustadz dapat mengirim data tanpa login Google
5
Otorisasi & Dapatkan URL: Klik Deploy, izinkan akses akun Google (Review Permissions > Advanced > Go to ... (unsafe) > Allow). Salin Web App URL yang berakhiran /exec.
6
Hubungkan ke Aplikasi: Tempelkan URL tersebut pada kolom di atas, lalu klik Tes Koneksi Spreadsheet dan Simpan Semua Perubahan Pengaturan. Selesai!
